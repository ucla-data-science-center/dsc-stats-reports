Reading These Metrics

  • Direct consultations = one interaction record (appointment or walk-in). Canceled appointments excluded.
  • Task cards = Trello cards assigned to DataSquad project work. Not equivalent to consultations.
  • Task activity (comment-weighted) = comment count on task cards — a workload proxy, not hours or outputs.
NoteData notes
  • Sources: LibInsight (scheduled exports + manual logs), DataSquad walk-in sign-in forms, Trello (historical task tracking)
  • Canceled appointments excluded from all direct consultation counts
  • Manual LibInsight logs deduplicated against scheduled exports using a same-provider/same-minute heuristic
  • Task metrics (Trello cards, comment-weighted activity) are not consultations — shown separately throughout
  • Full counting rules: Metrics Governance · About & methodology

NoteData notes
  • Direct consultations: LibInsight scheduled exports + manual logs (DSC staff); DataSquad walk-in sign-in forms
  • Canceled appointments excluded from all direct consultation counts
  • Deduplication: manual LibInsight logs matched against scheduled exports using a same-provider/same-minute heuristic; ~r kpi("libinsight_manual_logs_heuristic_duplicate_count") duplicates removed
  • Task metrics (Trello cards, comment-weighted activity) are shown separately — not comparable to consultation counts
  • Reportable filter: excludes Inbox, Future Projects/Ideas, Team Info lists; includes archived completed cards
  • Full rules: Metrics Governance · About
